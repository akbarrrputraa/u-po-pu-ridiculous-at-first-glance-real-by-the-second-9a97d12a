A deterministic program that writes one bizarre-but-bankable startup pitch (a single sentence, at most 200 characters) to `/output/entry.txt` for make.fun's "Ridiculous at First Glance, Real by the Second" bounty. The winning pitch: tiny funerals for dead houseplants, because grieving plant parents pay $29 for a miniature coffin, a eulogy, and a guilt-free goodbye instead of the bin.

## Run it

```sh
python3 main.py
```

The program holds a short ranked list of hand-written pitches, validates each against the brief (one sentence, 1–200 characters, naming the odd thing sold, who pays, and why it makes money), and writes the first valid one. No network, no clock, no randomness — two runs produce byte-identical output.
